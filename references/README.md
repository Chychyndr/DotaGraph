https://claude.ai/public/artifacts/ddbdfd38-f9ac-4261-a764-cdbac4e405ec

Use it for the interaction idea only:
- full graph first;
- select/search a hero;
- selected hero becomes prominent;
- unrelated graph dims;
- local counter relationships remain visible;
- compact contextual card.

Do not copy its visual styling, typography, support/core split, drift/breathing controls, or clutter.
