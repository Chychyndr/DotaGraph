# Project agent skills

This directory contains portable third-party skills vendored for DotaGraph agent workflows.

Available:
- caveman
- context-canary
- deslopify
- grill-me
- humanizer
- interface-kit
- junior-to-senior
- last-20-percent
- loop-factory

Project rules and recommended usage live in the root AGENTS.md.

Do not treat these files as DotaGraph runtime dependencies. Preserve their upstream license notices when updating or redistributing them.

Impeccable is intentionally used through its supported package/CLI workflow instead of being partially copied into this directory.
